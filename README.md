## Featured project

### [AI Transformation Copilot](https://github.com/yassine-el-maghraoui/ai-transformation-copilot)
A prototype that turns business requirements and supporting documents into a sourced AI transformation assessment: architecture, governance, ROI and KPIs.

- **5 specialist LLM agents** orchestrated with LangGraph, plus a reviewer and a bounded quality gate.
- **RAG with PostgreSQL / pgvector**, document ingestion and citation-reference checks.
- **Persistent workflow state**, model-call traces and cost tracking.
- **19-section reports**, with evaluation on 3 scenarios. The current small evaluation set passes the quality gate in **1 of 3 cases**; limitations and benchmark artifacts are documented.

**Stack:** Python · LangGraph · FastAPI · PostgreSQL · pgvector · Docker · Next.js
